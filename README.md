I work with TypeScript and Python across React/Next.js frontends, FastAPI and NestJS backends, and database integrations. My projects include property search, document retrieval, and audiovisual data processing. I am interested in security and understanding how systems work internally.

## Selected projects

### [Property Walay](https://github.com/Ninjaa-aa/property-walay)

A team final-year project at FAST-NUCES for searching Pakistani property listings. The repository combines a Next.js interface, a FastAPI backend, Supabase/PostgreSQL, property ingestion scripts, and recommendation features. It includes search, market trends, meeting workflows, and an AI assistant.

### [FYP Handbook RAG Assistant](https://github.com/Ninjaa-aa/fyphandbook-rag)

A Python assistant that answers questions from the FAST-NUCES FYP handbook with page citations and out-of-scope refusal handling. It combines dense retrieval with BM25, reciprocal rank fusion, reranking, and a Streamlit interface. The repository includes validation scripts and setup instructions.

### [DeSyst website](https://github.com/Ninjaa-aa/desyst-website)

A Next.js and TypeScript website with reusable React components, responsive layouts, and Framer Motion animations.

### [Urdu audiovisual speech dataset](https://github.com/Ninjaa-aa/urdu-av-dataset)

An early research pipeline for collecting, aligning, filtering, and reviewing Urdu audiovisual speech. The repository includes processing scripts, notebooks, tests, and a pilot report documenting results and limitations.
